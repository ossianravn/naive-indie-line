# Primitives

How Fineliner treats shadcn's parts (`src/fineliner/ui/`). Each file starts from the matching Patina UI file (`C:\CodexApp\patina-ui\src\patina\ui\<name>.tsx`, itself shadcn's `base-nova` source on Base UI) and keeps shadcn's component names, parts, props, variants and `data-slot` attributes, so Fineliner swaps in without JSX changes. Only the classes change, plus drawn marks where a part has one. The exemplars are `button.tsx`, `checkbox.tsx`, `input.tsx`, `label.tsx` and `card.tsx`.

## Steady fields, drawn boxes

Text sits inside fields, so their line stays steady: a crisp pen line with slightly uneven corners, no wobble. Everything else the hand draws: buttons, boxes, menus and dialogs get a frame whose edges run past the corners and bend with a seeded wobble, and choices are marked with pen marks (a tick, a dot, an underline) that are put down with a short wipe. The one thing to press, and a chosen option, is a pocket of solid ink with paper text. There is no shading, no gradient and no blur anywhere.

## Shared treatment

| Concern               | Treatment                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Text fields, triggers | `control-field` (steady pen line in `--input`, uneven 2/3 px corners, quiet placeholder, pressed line on hover, invalid and disabled states) at `h-control` (2.75 rem) or `h-control-compact`                                                                                                                                                                                                                                                                   |
| Drawn boxes           | `frame` (edges on `::before`/`::after`, wobble filter). Seed it from the part's own words with `frameStyle(children, style)` from `@/fineliner/lib/frame-style`, so neighbours wobble differently                                                                                                                                                                                                                                                               |
| Pressing harder       | Hover and open states thicken the drawn line: `hover:[--pen-weight:var(--pen-weight-pressed)]`                                                                                                                                                                                                                                                                                                                                                                  |
| Ink pocket            | `pocket` (a fill on `::before` with the frame's wobble, `styles/frames.css`) coloured with `before:bg-*`: solid `before:bg-pen` with `text-paper` for the main action and the chosen option; `before:bg-tint` for quiet fills and highlighted items. A pocket that must replay `put-down` is a child element instead (see `toggle.tsx`)                                                                                                                         |
| Pen marks             | `penMark(name, seed, "calm")` from `@/fineliner/pen/pen-marks` as an inline SVG string (see `checkbox.tsx`), or `<PenMark>` from `@/fineliner/drawing/pen-mark`. Names: tick, ring, dot, underline, strike, arrow, chevron, pill                                                                                                                                                                                                                                |
| Putting a mark down   | `put-down` (a short left-to-right wipe) on marks that appear when a part is checked, chosen or active                                                                                                                                                                                                                                                                                                                                                           |
| Floating surfaces     | `float-sheet` plus `frame`, and a `<span className="pen-shadow" aria-hidden />` child that follows the sheet in 40 ms later. Sheets grow from their trigger (`zoom-in-97`, `fade-in-0`, 150–200 ms, `ease-(--ease-out)`); none slide. `sideOffset={clearOfShadow}` from `@/fineliner/lib/frame-style` keeps a sheet that opens above or left clear of its trigger. The sheet's inner list scrolls, never the sheet, so overflow cannot clip the frame or shadow |
| Voices                | Control text in the reading serif at control size (`font-ui text-ui`); a field's label above its control, small headings, group labels and table heads in `label` (follows the labels setting); codes, prices and keys in `font-type` (Courier Prime)                                                                                                                                                                                                           |
| Focus                 | The page's dashed ring (`:focus-visible` in `base.css`). Remove shadcn's `outline-none`, `ring-*` and `focus-visible:border-ring` classes rather than restyling them                                                                                                                                                                                                                                                                                            |
| Selected, checked     | An ink pocket or a pen mark, never colour alone                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Highlighted item      | `pocket data-highlighted:before:bg-tint`, so the highlight wobbles too; it is also the item's focus mark                                                                                                                                                                                                                                                                                                                                                        |
| Disabled              | `text-pen-faint`; a drawn frame dims with its text (it draws in `currentColor`); fields go dashed. `cursor-not-allowed`; keep the words readable                                                                                                                                                                                                                                                                                                                |
| Invalid, destructive  | The correction pen: `text-correction` (frames follow `currentColor`); fields add the inset underline from `control-field`                                                                                                                                                                                                                                                                                                                                       |
| Text colours          | `text-pen` (reading), `text-pen-quiet` (secondary), `text-pen-faint` (disabled, hints), `text-correction`; `text-paper` on ink                                                                                                                                                                                                                                                                                                                                  |
| Corners               | Square or 1–3 px. Rounded only where the shape means it (switch track, slider thumb, radio, avatar), and then drawn with the wobble filter                                                                                                                                                                                                                                                                                                                      |
| Spacing               | The φ units (`p-snug`, `gap-tight`, `py-hair`…). Tailwind's numeric spacing only for optical nudges                                                                                                                                                                                                                                                                                                                                                             |
| Icons                 | Lucide at `size-4` where shadcn has them; a pen mark where the mark is the meaning (tick, dot, chevron)                                                                                                                                                                                                                                                                                                                                                         |
| Motion                | `press` on pressables; `put-down` on marks; `tw-animate-css` enter/exit classes from shadcn stay, 120–200 ms; reduced motion is handled in `controls.css` and globally                                                                                                                                                                                                                                                                                          |
| Line boil             | Not on controls. Drawings (avatar fallbacks, empty states) follow the boil setting through `Drawing`                                                                                                                                                                                                                                                                                                                                                            |
| Forced colours        | Wobble filters drop (`frames.css`); fills vanish there, so an ink pocket adds `forced-colors:before:border` and a chosen state uses `Highlight` (see `togglePocket`)                                                                                                                                                                                                                                                                                            |

Replace these shadcn tokens on sight: `bg-background` → `bg-paper`; `text-muted-foreground` → `text-pen-quiet`; `bg-muted`, `bg-accent` → `bg-tint`; `rounded-md`/`rounded-lg`/`rounded-xl` → square or `rounded-[2px]`; `shadow-*` → nothing, or `pen-shadow` on a floating surface; `text-sm`/`text-xs` → `text-small`/`text-label`; any `dark:` variant → nothing (night paper re-inks through tokens); `ring-*`, `outline-none` → nothing.

## Per part

| Part                  | Fineliner treatment                                                                                                                                                                                                                                                                                          |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Button                | Default an ink pocket (disabled: an empty dashed pocket); outline and destructive drawn frames; secondary a tint pocket; ghost a tint pocket on hover; link underlined                                                                                                                                       |
| Checkbox              | A drawn box; a tick that runs past the box, put down; partly checked a short stroke                                                                                                                                                                                                                          |
| Radio group           | A drawn circle (a round border with the wobble filter); chosen: an inked dot from `penMark("dot")`, put down                                                                                                                                                                                                 |
| Switch                | A drawn pill track; on: the track becomes an ink pocket and the paper thumb moves to the end                                                                                                                                                                                                                 |
| Input, textarea       | `control-field`; width set by the caller to fit the value                                                                                                                                                                                                                                                    |
| Select, native select | Trigger a `control-field` with a pen chevron; list a framed `float-sheet` with `pen-shadow`, tint-pocket highlight, a tick beside the chosen item                                                                                                                                                            |
| Field                 | Shadcn's field parts; `FieldLabel` in the label voice when it sits above its control in a vertical field, the reading voice beside a control; a `FieldLabel` that wraps a `Field` is a choice card with a drawn frame. `FieldDescription` in `text-pen-quiet text-small`, `FieldError` in the correction pen |
| Toggle, toggle group  | Pressed is an ink pocket with paper text, like the site's segmented controls; the group shares one drawn frame                                                                                                                                                                                               |
| Slider                | The track a pen rule; the range a heavier ink line; the thumb a paper circle with a drawn edge                                                                                                                                                                                                               |
| Progress              | A drawn frame track; the indicator an ink pocket that grows                                                                                                                                                                                                                                                  |
| Tabs                  | Labels in the reading voice; the active tab underlined by a pen stroke (`penMark("underline")`), put down; the list sits on a rule                                                                                                                                                                           |
| Badge                 | A small drawn frame round `label` text; default an ink pocket; destructive in the correction pen                                                                                                                                                                                                             |
| Alert                 | Open on the page: a pen mark by the title and a short ruled margin; destructive in the correction pen                                                                                                                                                                                                        |
| Avatar                | Image in a drawn circle; the fallback is the `portrait` drawing seeded by the name (`<Drawing object="portrait" seed={name} />`)                                                                                                                                                                             |
| Separator             | `rule` (one wobbling pen line); vertical: the same line turned                                                                                                                                                                                                                                               |
| Skeleton              | A `bg-tint` pocket with a slow pulse, in the content's own geometry                                                                                                                                                                                                                                          |
| Spinner               | A pen ring (`penMark("ring")`) turning                                                                                                                                                                                                                                                                       |
| Kbd                   | A typewriter keycap: `font-type`, a small drawn frame with a heavier bottom edge                                                                                                                                                                                                                             |
| Tooltip               | A slip of ink: `bg-pen text-paper`, `font-type text-small`, wobble on its edge. A defined term takes `term` (a dotted underline that firms while it shows)                                                                                                                                                   |
| Popover               | A framed `float-sheet` with `pen-shadow`                                                                                                                                                                                                                                                                     |
| Dialog, alert dialog  | A framed `float-sheet` with `pen-shadow`, centred over paper dimmed with `bg-paper/70`; title in the reading face at `text-lead`                                                                                                                                                                             |
| Dropdown menu         | The select list's surface and items; checkbox and radio items marked with a tick or dot; shortcuts in `font-type`; separators a `rule`                                                                                                                                                                       |

## Docs demos

Each primitive has `src/site/docs/demos/<name>.tsx`: a default export rendering `DemoSection` and `StateRow` blocks (from `../demo-kit`) that show every variant and state (default, hover-able, focus-able, checked or selected, invalid, disabled, empty, loading where they apply), plus `export const meta: DemoMeta` with `title`, `description` (one sentence on what it is for), `item` (its registry item, the file's base name) and `group` (Actions, Forms, Overlays, Navigation, Data display, Fineliner extras). `/docs/components/<name>` renders it. Example content comes from Listening Room, the demo product: a record shop with a catalogue, listening-session bookings, Thursday events and a short wine list. The first example row is also the part's preview on the Components index, so make it the most typical state. Helper modules for a demo go in a subfolder (`demos/<name>/`), since every `demos/*.tsx` becomes a page.

Size every control to its content at the call site (`w-64` for a name, `w-20` for a count); a control never stretches to fill a row just because it can.

## Class merging

Import `cn` from `@/fineliner/lib/utils`, never from `"cn"`. The plain `cn` reads Fineliner's theme names (`text-small`, `text-ui`, `px-snug`) as unknown and drops them when a conflicting-looking class follows. `lib/utils.ts` lists those names; add new theme names there.
