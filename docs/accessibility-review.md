# Accessibility review, v0.1

Status: review of 2 November 2026, before the v0.1 release. The bar is Patina UI's quality contract (`C:\CodexApp\patina-ui\docs\quality.md`): WCAG 2.2 AA for every component and every shipped workflow, in both themes. This records what was checked, how, what was found, what was fixed and what remains.

## What was checked

| Kind                   | Scope                                                                                                                                                                                                                                                |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Automated (axe-core)   | All 76 docs component pages (`/docs/components/<name>`, one per file in `src/site/docs/demos/`), the 7 block views (`/docs/blocks/view/<name>`), `/`, `/studio`, `/specimen` and six Listening Room pages, each in day and night: 92 pages, 184 runs |
| Keyboard               | Dialog, sheet, dropdown menu (plain, checkbox and radio items), select, combobox, command (inline and as a dialog), tabs, calendar, carousel and Listening Room's sidebar                                                                            |
| Names                  | Icon-only buttons across the kit, demos and Listening Room; drawings and lettering on every scanned page                                                                                                                                             |
| State and colour       | Selected, checked, current and invalid states in the kit's parts                                                                                                                                                                                     |
| Focus on night paper   | The dashed focus ring's colour and contrast on the recycled night card                                                                                                                                                                               |
| Contrast of quiet pens | `--pen-quiet` and `--pen-faint` against flat paper and the paper recess, every stock, day and night (the token checker covers only the full pens)                                                                                                    |

## How

axe-core 4 (devDependency) was injected from the dev server (`/@fs/…/node_modules/axe-core/axe.min.js`) into each page loaded in a 1280 × 900 iframe, with animations and transitions set to none, and run with its default rules (WCAG 2.0–2.2 A and AA plus best practices); the same page was then switched to `data-theme="night"` and run again. The loop ran in the built-in browser and kept its results in session storage. axe reports colour contrast over the paper textures as "needs review", not as a pass or a failure, so text contrast rests on `npm run check:contrast` and the token measurements below.

Keyboard paths were driven with real key presses (Tab, Shift+Tab, arrows, Home and End, Enter, Space, Escape) in a 1440 px window, recording each focus move and reading roles, names and `aria-*` state from the page. Names of drawings were read from every scanned page (`svg[role=img]` outside `aria-hidden`).

## Manual findings

| Area                          | Finding                                                                                                                                                                                                                                                                                                                                                   |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dialog, sheet, command dialog | Focus moves to the first field (or the close button), Tab wraps inside, Escape closes and focus returns to the trigger. Each is named by its title                                                                                                                                                                                                        |
| Dropdown menu                 | Enter or ArrowDown opens on the first item; arrows, Home and End move; Escape closes and returns focus. Checkbox and radio items expose `menuitemcheckbox` / `menuitemradio` with `aria-checked`, in labelled groups. Shortcut letters are part of each item's name ("Hold H"), as in shadcn                                                              |
| Select                        | `combobox` trigger, named by its label; arrows move through options with `aria-selected`; Enter chooses, closes and returns focus                                                                                                                                                                                                                         |
| Combobox                      | Typing filters, arrows move `aria-activedescendant`, Escape closes and keeps focus in the field. The chevron button had no name (fixed)                                                                                                                                                                                                                   |
| Command                       | The query is a named `combobox`; arrows move the active result; the separators broke the listbox's structure (fixed)                                                                                                                                                                                                                                      |
| Tabs                          | Arrows move focus along the list without choosing (manual activation); Tab goes to the chosen panel, which is named by its tab                                                                                                                                                                                                                            |
| Calendar                      | Arrows move by day and week, Enter chooses; month buttons are named. Day names read "Thursday, November 5th, 2026", which leaves out the visible numeral "5" as a word (WCAG 2.5.3; fixed)                                                                                                                                                                |
| Carousel                      | A named region with "slide" groups ("1 of 6"); previous and next are named, disabled at the ends; ArrowRight on the carousel moves; the live count announces "2 / 6"                                                                                                                                                                                      |
| Sidebar (Listening Room)      | Tab order runs skip link, brand, sections (current page `aria-current="page"`), account, trigger, page. Items keep their names when collapsed to icons. The column was outside every landmark, the trigger did not say whether the sidebar was open, and the account button read the avatar's initials before the name (all fixed)                        |
| Icon-only buttons             | Every one in the kit, demos and Listening Room has a name except the combobox chevron (fixed)                                                                                                                                                                                                                                                             |
| Drawings                      | **Every decorative drawing (`title=""`) was named after its object, three times over**: `tile()` received `undefined` for an empty title and fell back to its default label, on every take. On the home page alone a screen reader met 27 named "Armchair", "Record"… images that the page meant to hide (fixed in the pen engine). Lettering was correct |
| Drawings, meaningful          | After the fix: the hero scene, the studio scene and portraits (avatars without initials) are named once; Listening Room's record page drew a generic "Record" before the record's own heading (now decorative)                                                                                                                                            |
| State never by colour alone   | Holds: chosen options are ink pockets, ticks or dots; the current tab an underline; today a ring; disabled days struck through; invalid fields add an underline and a message; chart series differ by mark style                                                                                                                                          |
| Focus on night paper          | The ring is a 1.5 px dashed outline in the pen, 4 px outside the control; on recycled night it is `#dde3f2` on `#1c2131`, about 12:1, and it sits on paper beside ink pockets, never on them                                                                                                                                                              |

## What was fixed

| File                                   | Change                                                                                                                                                                                          |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/fineliner/pen/library.ts`         | `tile()` takes `""` as "decorative" and only falls back to the object's name when no label is passed, so `title=""` hides the drawing and only the first take is ever named                     |
| `src/fineliner/pen/drawing-svg.ts`     | Passes the label through as given instead of turning `""` into `undefined`                                                                                                                      |
| `src/fineliner/ui/calendar.tsx`        | Default `labels.labelDayButton` names a day "Thursday 5 November 2026" (with "Today, " and ", selected" as before), so the visible numeral is a word of the name; a caller's `labels` still win |
| `src/fineliner/ui/combobox.tsx`        | The chevron trigger inside `ComboboxInput` is named "Show options"                                                                                                                              |
| `src/fineliner/ui/command.tsx`         | `CommandSeparator` is `aria-hidden`: a listbox may own only groups and options, and cmdk fixes the separator's role                                                                             |
| `src/fineliner/ui/item.tsx`            | `ItemSeparator` is `aria-hidden`, for the same reason inside an item group's list                                                                                                               |
| `src/fineliner/ui/sidebar.tsx`         | `SidebarTrigger` carries `aria-expanded` (the open state on wide screens, the sheet's on phones)                                                                                                |
| `src/fineliner/blocks/sign-in-01.tsx`  | The email field's `autocomplete="username email"` (an invalid token list) is `username`, which password managers pair with `current-password`                                                   |
| `src/site/listening-room/shell.tsx`    | The sidebar is the shop's navigation landmark (`role="navigation"`, "Listening Room"); the account button's avatar is hidden, so it reads "Maya Singh, Behind the counter"                      |
| `src/site/listening-room/evenings.tsx` | Each evening row in the item group is a `listitem`; without the role the list owned each row's progress bar                                                                                     |
| `src/site/listening-room/record.tsx`   | Each session link sits in its own `listitem`; the generic record drawing before the heading is decorative                                                                                       |
| `src/site/docs/demos/skeleton.tsx`     | Loading placeholders are `role="status"`, so their `aria-label` is allowed and announced                                                                                                        |
| `src/site/docs/demos/resizable.tsx`    | The scrolling list in the horizontal example is focusable and named, so it scrolls from the keyboard                                                                                            |
| `src/site/docs/demos/sidebar.tsx`      | The account avatar is hidden, as in Listening Room                                                                                                                                              |

`npm run registry` rebuilt the seven changed items (calendar, combobox, command, item, pen, sidebar, sign-in-01).

### Not covered

Forced colours, reduced motion and right-to-left were not re-checked in this pass; nor were screen readers themselves (names and roles were read from the DOM, not heard). Keyboard paths were walked at 1440 px only, so the phone sidebar sheet, the drawer's drag and the menubar, navigation menu, context menu, hover card, slider, input OTP and toggle group were covered by axe but not walked by hand. The browser pane was hidden, so transitions were turned off to see settled states; the motion itself was not watched.
